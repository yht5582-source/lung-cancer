# 肺癌治療指引｜繁體中文

互動網站：https://yht5582-source.github.io/lung-cancer/

本工具協助醫師依病理、分期、分子標記與病人狀況（ECOG、年齡、身高體重、腎肝功能、腦轉移、免疫或 cisplatin 禁忌）選擇治療方式與藥物：先決定治療目的，再排列首選、替代與特定情況處方，列出標準劑量、本例估算劑量（Mosteller BSA、Calvert carboplatin、體重級距）、療程、依據試驗、器官功能警示與台灣健保條文狀態。另保留 TNM9 分期、病理與分子、台灣健保、六個虛構病例與二十題測驗作為輔助。

**臨床決策輔助，不能取代醫師判斷。** 劑量為仿單或樞紐試驗之標準成人劑量，處方前須依台灣仿單、器官功能與藥師覆核；不判定健保核准。輸入資料只在瀏覽器計算。本版未經外部臨床專家驗證。

## 執行

純靜態 HTML/CSS/JavaScript，不需要安裝相依套件或建置。用任意靜態伺服器開啟本目錄，例如 `python3 -m http.server 8765`，再開啟 `http://localhost:8765/`。ES modules 需透過 HTTP 開啟。

測試：Node 18以上執行 `node --test tests/*.test.mjs`。

## 來源與範圍

內容查核日：2026-10-28（Asia/Taipei）。每個模組、病例及試題附來源，全部來源與版本記錄在 `content.js`，網站「來源與版本」頁可直接查閱。

- TNM9：IASLC官方分組及原始研究；特別保護未知輸入、N2a/N2b、M1c1/M1c2。
- WHO第5版胸腔腫瘤公開分類架構；ESMO 2025早期／局部晚期、2024 Pan-Asian分子指引、2021 SCLC加2024 ADRIATIC證據；ASCO 2026.3.1及NCI公開證據補充。
- NCCN已確認公開發表4.2026版本；專業版全文未能完整存取，**不宣稱為最新版逐條翻譯或完整一致性審查**。
- 健保：2026-10-28 逐條核對第9節抗癌瘤藥物（115.09.22 版，含 115.10.01 生效條文）所有肺癌相關藥品，並確認截至 115.10.28 的法規公告無後續肺癌藥品修訂。網站節錄條件，送審仍須合併通則（含通則十二）與指定品項。
- NGS一般要求與歷史附表可讀；2026完整現行適應症未完成核對，明確標示待核對。**未核對不是不給付**。
- 第9節未見給付條文的藥品（selpercatinib、pralsetinib、sotorasib、adagrasib、HER2 突變用 T-DXd 等）標為「未見」，不推定給付，也不等於確認未收載；指引、藥證與支付標準各自查核。

## 檔案

- `content.js`：來源、教學內容、六病例與20題。
- `rx.js`：治療指引引擎——情境→處方排序、劑量計算、個案化警示、各處方健保條文判讀。
- `logic.js`：分期、臨床判讀與防呆、測驗計分。
- `app.js`：治療指引頁與其餘六模組、病例載入、搜尋、互動與列印。
- `tests/rx.test.mjs`：處方排序、健保判讀、劑量計算與全輸入組合掃描。
- `tests/clinical.test.mjs`：分期矩陣與邊界、分流、病例、題目、計分。

## 版本紀錄

- v1.1（2026-10-28）：T1mi 合併 N＋或 M1 改依 T1a 分組（原本誤顯示無法分組）；KRAS G12C／HER2 第一線補上 PD-L1 分流說明；臨床路徑條件變更即時更新建議，依病理停用不相容情境，SCLC 停用驅動基因／PD-L1；分期表標示命中格；測驗標出未作答題號；手機導覽自動捲到目前分頁；加 favicon。

- v1.2（2026-10-28）：依健保第9節（115.09.22）逐條查證：EGFR（含 aumolertinib、dacomitinib 無腦轉移、erlotinib＋bevacizumab）、ALK、ROS1（repotrectinib）、BRAF、MET、NTRK、amivantamab、9.69 免疫（術前 nivolumab、各藥 PD-L1 門檻、eGFR >60 等共通條件）、pemetrexed／bevacizumab；臨床路徑結果新增綠色「台灣健保條文」區塊；病例健保欄改為已核對條文。

- v2.0（2026-10-28）：改為治療指引設計：首頁「治療指引」依「治療目的 → 病人評估 → 推薦處方」流程，涵蓋 NSCLC 早期／可切除／局部晚期／轉移性各驅動基因與後線、SCLC 有限期／擴散期／復發，共 60 餘個處方；教學模組保留於後。
