# 肺癌臨床教學｜繁體中文

互動網站：https://yht5582-source.github.io/lung-cancer/

本工具供住院醫師與主治醫師教學，包含診斷與病理、TNM第9版分組、NSCLC／SCLC治療路徑、分子標記、台灣健保條文查核、六個完整虛構病例，以及住院醫師／主治醫師各十題含解析與計分的測驗。

**臨床決策輔助，不能取代醫師判斷。** 不輸入真實病人資料，不提供劑量或健保核准判定。本版未經外部臨床專家驗證。

## 執行

純靜態 HTML/CSS/JavaScript，不需要安裝相依套件或建置。用任意靜態伺服器開啟本目錄，例如 `python3 -m http.server 8765`，再開啟 `http://localhost:8765/`。ES modules 需透過 HTTP 開啟。

測試：Node 18以上執行 `node --test tests/*.test.mjs`。

## 來源與範圍

內容查核日：2026-10-28（Asia/Taipei）。每個模組、病例及試題附來源，全部來源與版本記錄在 `content.js`，網站「來源與版本」頁可直接查閱。

- TNM9：IASLC官方分組及原始研究；特別保護未知輸入、N2a/N2b、M1c1/M1c2。
- WHO第5版胸腔腫瘤公開分類架構；ESMO 2025早期／局部晚期、2024 Pan-Asian分子指引、2021 SCLC加2024 ADRIATIC證據；ASCO 2026.3.1及NCI公開證據補充。
- NCCN已確認公開發表4.2026版本；專業版全文未能完整存取，**不宣稱為最新版逐條翻譯或完整一致性審查**。
- 健保已核對第9節完整檔（官方索引115.09.22更新，含115.10.01生效條文）、EGFR TKI及免疫藥品修訂附件；網站只節錄明示條件，送審仍須合併通則、後續公告與指定品項。
- NGS一般要求與歷史附表可讀；2026完整現行適應症未完成核對，明確標示待核對。**未核對不是不給付**。
- 未逐項核對的標靶或新適應症不推定給付；指南、藥證與支付標準各自查核。

## 檔案

- `content.js`：來源、教學內容、六病例與20題。
- `logic.js`：分期、決策分流、測驗計分；不做個案給付核准。
- `app.js`：七模組導覽、病例載入、搜尋、互動與列印。
- `tests/clinical.test.mjs`：分期矩陣與邊界、分流、病例、題目、計分。
